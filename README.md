## The word

**petrichor** — the smell of rain on dry earth. It was the first word that came to mind, and it earns its place: it is surprising (most readers have smelled it a hundred times without knowing it has a name), vivid (one word conjures a whole summer storm — dust, heat, the first drops), and it sounds like what it means, soft and earthy with that crisp "ch" in the middle. No safe filler, no second draft — just the word itself.

## How to run

```sh
node main.ts
```

This writes exactly one word to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program guards that the word is a single token of 1–24 characters before writing.
